# Benchmarks

Benchmarks for the `admiral-adpc` skill are tracked as GitHub issues with the
`benchmark` label at https://github.com/RConsortium/pharma-skills/issues, and
synced into `_automation/evals/` by the `issue-to-eval` skill.

Inputs come from [`{pharmaversesdtm}`](https://pharmaverse.github.io/pharmaversesdtm/)
(PC, EX, VS) and [`{pharmaverseadam}`](https://pharmaverse.github.io/pharmaverseadam/)
(ADSL), which any contributor can reproduce.
